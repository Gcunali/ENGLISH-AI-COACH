# TOEIC Daily Practice Specification

TOEIC Daily Practice is separate from the global daily practice system. It creates a deterministic 12-question snapshot: 5 Listening and 7 Reading, choosing supported weaknesses where possible and otherwise stable individual-question Parts.

History is stored only in TOEIC personalized tables. Results are raw only; no XP, CEFR, global Review, course progress or scaled TOEIC estimate is modified.
