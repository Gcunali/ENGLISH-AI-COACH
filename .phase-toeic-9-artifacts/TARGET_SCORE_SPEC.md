# Target Score Specification

- Presets: 550, 650, 750, 850 and 900+; custom values accept 10–990.
- Default: 750, stored locally as `settings.toeic_target_score`.
- The target affects recommendations and the displayed planning gap only.
- It never changes raw correctness, first attempts, score profiles, scaled estimates or uncertainty ranges.
- Latest estimate and range are labelled unofficial; no exact real-exam outcome is claimed.
