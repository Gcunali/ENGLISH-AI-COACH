# Part 6 Runtime Specification

Part 6 is untimed and contains four text sets of four A–D questions (16 total). Each set keeps its passage visible, locks every first submission, and withholds correctness, keys, explanations and completed text until all four answers are stored. Learning Mode then unlocks authored set feedback; Simulation Mode never does so during the session. A snapshot freezes form/set/question IDs, versions, order and authored content. Resume is allowed at any point with prior answers locked. Results are raw X/16 only; no Reading estimate exists before Part 7 completes 100/100 coverage.
