## Verified in source/automated checks

- Skip link targets the focusable main content.
- Page titles use semantic headings; shared cards and stages preserve heading hierarchy.
- Form controls have labels or accessible names.
- Progress elements expose labels and numeric values.
- Dialogs expose dialog semantics and explicit confirmation/cancel actions.
- Live error/status regions exist for async voice, analysis, save and restore flows.
- Visible focus uses a blue outline with offset.
- Controls have a shared 44 px minimum target.
- Reduced-motion preference disables nonessential animations/transitions.
- Higher-contrast preference strengthens borders and muted text.
- Status is communicated with text/icon/state in addition to color.
